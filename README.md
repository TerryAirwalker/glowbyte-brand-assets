# glowbyte-brand-assets

Публичные бинарные ассеты бренда GlowByte — логотипы и шрифты для использования
дизайн-скиллом `glowbyte-design` при сборке материалов (слайды, документы, баннеры).

Источник правды по токенам (цвета/шрифты/правила) — `manifest.json` в
[glowbyte-brandbook](https://github.com/TerryAirwalker/glowbyte-brandbook).

## Структура

- `logos/glowbyte-logo-red.svg` — основной логотип (рыжий), для белого/чёрного фона.
- `logos/glowbyte-logo-white.svg` — белый логотип, для цветного/чёрного фона.
- `fonts/Montserrat-{Regular,Bold}.ttf` — корпоративный шрифт (Google Fonts, OFL).
- `fonts/JetBrainsMono-{Regular,Bold}.ttf` — моноширинный шрифт для кода/данных (Apache 2.0).
- `skill/glowbyte-design/SKILL.md` — копия потребительского скилла (публикуется `release.py`).
